This week I shipped a faster, more findable portfolio.

No new features for the sake of it. Just the boring stuff that matters:

⚡ Speed
The home page is now a server component. Static sections ship no client JS. The GitHub calendar and testimonials mount just before they scroll into view. Dropping mathjs for plain Math cut 118 KB.

🔎 Findability
Every page got its own canonical URL (they were all inheriting the home page's). Project pages got structured data. Added an llms.txt for AI assistants.

🔗 Small things
Short links like minianon.in/resume and /mentor. A branded 404 page. All Topmate reviews now load live in a scrolling row.

Honest lesson: the canonical bug had been there all along. Every page was telling Google "I'm the home page". Nobody sees that, but search engines do.
